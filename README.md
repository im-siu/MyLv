# MyLv

MyLv는 사용자의 목표, 할 일, 스킬 성장을 캐릭터와 레벨링 경험으로 연결하는 iOS 앱입니다.

## 프로젝트 개요

- 플랫폼: iOS
- 개발 환경: Xcode
- 언어: Swift
- UI 프레임워크: SwiftUI
- 저장소: https://github.com/im-siu/MyLv
- 기본 브랜치: `main`

## 핵심 방향

- 사용자가 목표를 만들고 관리할 수 있도록 합니다.
- 목표를 달성하기 위한 할 일을 관리할 수 있도록 합니다.
- 반복적인 행동과 달성 경험이 스킬 성장으로 이어지도록 합니다.
- 캐릭터, 레벨, 경험치 요소를 통해 성장감을 제공합니다.

## 현재 상태

- 기본 Xcode 프로젝트 생성 완료
- Git 저장소 초기화 완료

## 실행 방법

1. Xcode에서 `MyLv.xcodeproj`를 엽니다.
2. 실행할 시뮬레이터 또는 실제 기기를 선택합니다.
3. Run 버튼을 눌러 앱을 실행합니다.
