# Project Overview

## 앱 목적

MyLv는 사용자가 목표와 할 일을 관리하면서 자신의 성장 과정을 시각적이고 게임적인 경험으로 느낄 수 있도록 돕는 iOS 앱입니다.

단순히 할 일을 체크하는 데서 끝나지 않고, 사용자의 반복적인 행동이 스킬 성장, 경험치, 레벨, 캐릭터 성장으로 이어지는 구조를 지향합니다.

## 핵심 사용자 경험

사용자는 목표를 생성하고, 목표 달성을 위한 할 일을 관리합니다.

할 일 완료나 반복적인 실천은 특정 스킬의 성장으로 연결됩니다. 사용자는 자신의 노력이 누적되는 과정을 레벨과 캐릭터 변화를 통해 확인할 수 있습니다.

## 주요 기능 방향

- 목표 관리
- 할 일 관리
- 스킬 관리
- 캐릭터 선택
- 경험치 및 레벨 시스템
- 성장 상태 시각화

## 화면 방향

현재 기획 자료 기준으로 다음 화면들이 주요 흐름에 포함됩니다.

- HomeView
- GoalEditorView
- TodoEditorView
- SkillView
- SkillEditorView
- CharacterSelectView

## 기술 방향

- SwiftUI 기반으로 개발합니다.
- 초기에는 기본 Xcode 프로젝트 구조에서 시작합니다.
- 앱 규모가 커지면 MVVM 구조를 기준으로 View, ViewModel, Model을 분리합니다.
- 데이터 처리와 외부 연동이 필요해지면 Service, Repository 계층을 도입합니다.
